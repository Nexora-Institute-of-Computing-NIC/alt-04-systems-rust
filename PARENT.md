# Parent Comparison

**Parent:** [CS302 - Operating Systems](https://github.com/Nexora-Institute-of-Computing-NIC/sem-03-cs302-operating-systems)
**This edition:** Rust

## What stays the same

- Learning outcomes
- Unit structure and lecture topics
- Lab and project briefs
- Assessment scheme

## What changes

- **Language:** Rust instead of the parent's language
- **Code:** all examples, starters, and solutions
- **Tooling:** build system, package manager, testing framework
- **Idioms:** examples follow Rust conventions

## Differences in detail

- All code examples in Rust
- Ownership and borrowing replace C pointer discipline
- All memory bugs become compile errors
- Adds a unit on Rust's async runtime
- Labs use Rust's standard library where possible
